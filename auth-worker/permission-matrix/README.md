# Auth permission matrix golden (auth-worker half)

`golden.json` is one row per (principal × guarded route): the HTTP status
the worker answered, plus the ids a list route returned and accepted/rejected
for an event write. It is produced by
`src/__tests__/permission-matrix.test.ts`, which sends every request through
the worker's handlers against a PGlite fixture, and it is the `auth-matrix`
gate's review artifact (docs/RELEASE-RISK-GATES.md "Gates").

- A row that differs fails the test. Do not edit this file by hand.
- To change a permission answer on purpose, regenerate and let the diff be
  reviewed: `UPDATE_AUTH_MATRIX=1 pnpm exec vitest run src/__tests__/permission-matrix.test.ts`
- A PR that changes this file stays held (the gate job fails on a changed
  golden) until a person adds `release:approved`.
