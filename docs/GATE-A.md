## How each row is measured

- **Native format integrity.** Proxy checks in `idmlAdapter.validate`. The InDesign open/preflight/save/reopen gate from aquilla `docs/IDML_ADOBE_VALIDATION.md` must run on these outputs before this row can pass.
- **Text preservation.** Translate every unit (pseudo-German, +30%), render, re-extract, compare unit-by-unit by structural path.
- **Round-trip fidelity.** Compare raw local ZIP records of every non-story member; compare text-masked story skeletons; render with no translations.
- **Unchanged-content stability.** 60 generated documents (12–40 paragraphs), human edits on every third paragraph, then random edit scripts (modify/insert/delete/move/split/merge), full sync through the watched-folder pipeline.
- **Incremental updates.** Same scenarios; counts the jobs actually sent to the translator.
- **Identity reconciliation (precision / recall).** Ground-truth edit scripts (test/edit-scripts.ts) over a deliberately small vocabulary, which makes unrelated paragraphs look more alike than real prose.
- **Patch idempotency.** Property test over batches mixing inserts, chained replaces, concurrent siblings and all three authorities.
- **Event ordering.** Property tests: random permutation of each batch / fact set, with duplicates for the ledger.
- **Conflict safety.** duplicate paragraph with a human edit changes multiplicity; edit equally close to two earlier paragraphs; two people edit the same translation concurrently; agent output tries to overwrite a human translation; stale patch against changed target; designer changed story markup in the target while the source changed the same story; a target file exists that this system never published; a human edit made directly in the published target is not overwritten by a re-sync
- **Recovery.** Four source revisions, two locales; `ambient rollback --to <publish>`.
- **Rendering: overflow and missing content.** Calibrated geometric estimate (frames, threading, columns, insets, style point size/leading, per-script glyph widths). Real overset needs InDesign's composer; the estimator is a triage signal until the InDesign Server oracle is wired in (docs/LAYOUT.md).
- **Incremental cost vs full regeneration.** Engine time with the zero-cost pseudo translator; with a real model the saving is dominated by the jobs avoided.

## Reading this honestly

- **NOT VERIFIED** means the claim needs Adobe software we do not run here. The structural proxy is necessary, not sufficient.
- **PARTIAL** means the mechanism exists and is tested, but its ground truth is an estimate.
- Gates B (customer) and C (market) cannot be measured by code; see docs/RESEARCH-PLAN.md.
