Codex / design spec 2026.04.29 v1 — project setup

Setup happens to you, not in front of you.

Founders create a project in 30 seconds and translate inside the next 30. Joiners translate within 60 seconds of clicking their invite link. AI provider is a personal credential, prompted just-in-time. The system message is a project artifact, surfaced in the editor with a visible "shared with collaborators" mark. No checklist drawer.

Type

Fraunces (display, variable SOFT)
Instrument Sans (body)
JetBrains Mono (meta + keys)

Palette

cream · paper · ink
sienna (personal) · moss (shared)

Principles

  • URL implies intent. /?invite=… → joiner; bare root → founder.
  • Setup is just-in-time. The provider sheet shows when you press Translate, not before.
  • Altitude is communicated in the chrome, never via tutorial. Sienna = personal. Moss = shared.
  • Nudges are earned. The "customize your instructions" prompt only appears after meaningful use.

08 / 08

The earned nudge

For founders who skipped customizing AI instructions. Appears after they've accumulated meaningful work (10 verses translated, or 3 days of use — whichever comes first). Dismissable; resurfaces after another 25 verses if dismissed. Never appears for joiners.

What this design removes.

−6
Wizard steps

The 6-step OnboardingWizard collapses into one form for founders, zero-step for joiners.

−4
Checklist tiles

SetupChecklistDrawer is gone. Provider, instructions, invites, voice — all surface contextually.

+2
Tracks, separated

Founder and joiner are distinct paths, implied by URL — not branched by checklist state.

Open questions for v1.5.

Org-managed keys

For non-technical translators, an org-paid pooled provider may be necessary. Not v1, but the provider sheet should leave room for an "Use my organization's plan" option.

Project sync

The shared system prompt is per-project, but sync is happening via y-partyserver. The "Last saved 2m ago by Maria" line implies Yjs presence — confirm that's wired.

Nudge cadence

10 verses is a guess. Instrument the nudge: % accept, % dismiss, time-to-customize. Tune the threshold against actual data after 30 days.
