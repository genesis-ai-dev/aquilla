# UI Localization Phases 0–2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Aquilla SPA's translator-facing surfaces render in Thai, Burmese, and Patani Malay, shipped as a self-contained release for Biblica's late-August rollout.

**Architecture:** Restructure the four contended i18n registries so one file per namespace carries that namespace's keys, context, and surface declarations — then fan out one subagent per namespace to extract strings, and run a serial capture → export → translate → import loop. Three barrel files preserve every import path and derived type that exists today, so no consumer outside `src/lib/i18n/` changes.

**Tech Stack:** TypeScript, React 19, Vitest (happy-dom), Playwright, Tailwind v4, `tsx` scripts. Existing i18n machinery from AQU-511 and AQU-832.

**Spec:** `docs/superpowers/specs/2026-08-10-ui-localization-all-surfaces-design.md`

## Global Constraints

- No `any`. TypeScript strict; `pnpm build` runs `tsc -b`.
- `@/` resolves to `./src`. Target files under ~500 lines.
- `pnpm test` is the CI gate and **already fails** on a message key whose namespace has no context block — every task must leave the suite green.
- Message keys are namespaced `<namespace>.thing`; the namespace is the segment before the first `.`.
- Marketing entries (`homepage.html`, `bible-translation.html`, `beta.html`, `case-study*.html`, `src/pages/Homepage/`, `src/pages/CaseStudy/`, `src/pages/Beta/`, `src/pages/PrivacyPolicy.tsx`) are **English only** — they prerender and never mount `I18nProvider`. Never call `t()` there.
- Strings originating in `src/lib/**` are out of scope (AQU-510). `t()` is a hook.
- Locales `th`, `my`, `mfa`, `ar` are already registered in `src/lib/i18n/locales.ts`. Do not edit that file.
- `src/lib/i18n/messages/<locale>.ts` files are generated by `pnpm i18n:import`. Never hand-edit.
- Default locale stays `en`; no test or spec may set `localStorage["aquilla-locale"]`, or English-text e2e assertions will break.

## File Structure

**New — one file per namespace, owned by exactly one agent:**

- `src/lib/i18n/namespaces/types.ts` — leaf module holding `ContextEntry`, `ScreenshotSurface`, `NamespaceModule<K>`. Imports nothing from the i18n barrel, which is what breaks the import cycle.
- `src/lib/i18n/namespaces/<ns>.ts` — one per namespace: its `keys`, its `context` block, its `surfaces`. These three change together, so they live together.
- `scripts/i18n-shots/<ns>.ts` — that namespace's Playwright surface drivers (Node/Playwright, so it cannot live under `src/`).

**Modified — become thin barrels, keeping every existing import path valid:**

- `src/lib/i18n/messages/en.ts` — spreads each namespace's `keys`; still exports `en`, `MessageKey`, `Catalog`.
- `src/lib/i18n/context.ts` — collects each namespace's `context` into `CATALOG_CONTEXT`; keeps `namespaceOf`, `placeholdersIn`, `resolveKeyContext`, `MESSAGE_KEYS`, `catalogContextIssues`, `CONTEXT_SCHEMA_VERSION`.
- `src/lib/i18n/screenshots.ts` — spreads each namespace's `surfaces` into `SCREENSHOTS`; keeps `SCREENSHOT_DIR`, `ScreenshotId`, `isScreenshotId`, `screenshotPath`, `screenshotSurface`.
- `scripts/i18n-shots.ts` — merges the per-namespace driver maps; capture loop unchanged.

**Deliberate type tradeoff, stated once:** in namespace modules `ContextEntry.screenshot` is typed `string`, not `ScreenshotId` — `ScreenshotId` is derived from all surfaces, so keeping it would reinstate the cycle. The existing runtime lint (`catalogContextIssues()` check 4, asserted by `context.test.ts:50`) still rejects an undeclared surface id, so coverage is preserved; it moves from compile time to the test gate. Each namespace's `context.keys` **is** typed against that namespace's own keys, which newly makes cross-namespace context entries a compile error.

```ts
/**
 * Leaf types for per-namespace catalog modules (AQU-511 fan-out).
 *
 * This module imports nothing from the i18n barrels on purpose. `context.ts`
 * and `messages/en.ts` are built FROM the namespace modules, so a namespace
 * module that imported its types from them would close an import cycle.
 *
 * `ContextEntry.screenshot` is `string` rather than `ScreenshotId` for the same
 * reason — the id union is derived from every namespace's surfaces. Undeclared
 * ids are still rejected at test time by `catalogContextIssues()`.
 */

export interface ContextEntry {
  description: string
  screenshot?: string
  maxLength?: number
  placeholders?: Record<string, string>
}

export interface ScreenshotSurface {
  id: string
  title: string
  route: string
  notes: string
}

/**
 * One namespace's contribution to the catalog: its English strings, its context
 * block, and the surfaces its context references. `context.keys` is typed
 * against this namespace's own keys, so an entry for another namespace's key is
 * a compile error rather than a lint failure.
 */
export interface NamespaceModule<K extends string> {
  keys: Record<K, string>
  context: {
    _context: ContextEntry
    keys?: Partial<Record<K, ContextEntry>>
  }
  surfaces: readonly ScreenshotSurface[]
}

/** Identity helper that pins `K` to the literal keys of `keys`. */
export function defineNamespace<K extends string>(mod: NamespaceModule<K>): NamespaceModule<K> {
  return mod
}
```

## Task 5: Add the duplicate-string guard

**Files:**
- Create: `src/lib/i18n/namespaces/no-duplicates.test.ts`

**Interfaces:**
- Consumes: `NAMESPACES` (Task 2), `common` (Task 4).
- Produces: the invariant that lets Task 7's fan-out run unsupervised.

- [ ] **Step 1: Write the failing-by-construction test**

```ts
// src/lib/i18n/namespaces/no-duplicates.test.ts
import { describe, expect, it } from "vitest"
import { NAMESPACES } from "./index"
import { common } from "./common"

const normalize = (s: string) => s.trim().toLowerCase().replace(/[…:]+$/, "")

describe("catalog has no duplicate English strings (AQU-511)", () => {
  it("does not re-key a string that common.* already provides", () => {
    const shared = new Map(
      Object.entries(common.keys).map(([key, value]) => [normalize(value), key]),
    )
    const offenders: string[] = []
    for (const ns of NAMESPACES) {
      if (ns === common) continue
      for (const [key, value] of Object.entries(ns.keys)) {
        const existing = shared.get(normalize(value))
        if (existing) offenders.push(`${key} duplicates ${existing} ("${value}")`)
      }
    }
    // Every duplicate is a string a human translator is asked to translate
    // twice, in four locales. Reuse the common.* key instead.
    expect(offenders).toEqual([])
  })

  it("has no two namespaces claiming the same key", () => {
    const seen = new Set<string>()
    const collisions: string[] = []
    for (const ns of NAMESPACES) {
      for (const key of Object.keys(ns.keys)) {
        if (seen.has(key)) collisions.push(key)
        seen.add(key)
      }
    }
    // A collision means one namespace's spread silently overwrites another's.
    expect(collisions).toEqual([])
  })
})
```

```ts
// e2e/specs/i18n/locale-switch.spec.ts
import { expect, test } from "@playwright/test"
import { seedProject } from "../../support/seed-project"   // match this repo's helper path

test("switching to Burmese localizes the chrome without exposing raw keys", async ({ page }) => {
  const { projectId } = await seedProject(page)
  await page.goto(`/project/${projectId}`)
  await page.getByLabel("Language").selectOption("my")
  // Raw keys leaking through means a catalog key exists with no fallback path.
  await expect(page.locator("body")).not.toContainText(/\b(nav|common|editor)\.[a-z]/)
  await expect(page.locator("html")).toHaveAttribute("lang", "my")
  // The nav must actually be translated, not silently falling back to English.
  await expect(page.getByRole("navigation")).not.toContainText("Projects")
})
```
