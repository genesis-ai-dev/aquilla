## Scope boundary — where the swarm necessarily stops

Task 9 Steps 3–5 (create one Aquilla project per locale, run the translation agent,
**Biblica teams review the drafts in-app**, then `pnpm i18n:import`) are gated on people, not
code. The swarm terminates after Task 9 Step 2 (capture + export) with the interchange files
ready to hand off. Do not fabricate translated catalogs to close the loop — an unreviewed
`messages/my.ts` shipped as if reviewed is worse than an empty one, because the English
fallback is honest and a bad translation is not.

## Deviation from the written plan (deliberate)

The plan has each namespace agent append its import + array entry to
`src/lib/i18n/namespaces/index.ts`. That is the *only* shared file in the fan-out, and across
9 worktree-isolated agents it is a guaranteed 9-way conflict on the same two lines.

**Instead: agents never touch `namespaces/index.ts`.** Each agent creates only its own
`namespaces/<ns>.ts` and `scripts/i18n-shots/<ns>.ts`. The orchestrator wires all 9 into
`namespaces/index.ts` and `scripts/i18n-shots/index.ts` after merging, in one commit. This
removes the union-merge problem entirely rather than managing it.

Consequence for agents: their new namespace is **not** live in the barrels while they work, so
`pnpm i18n:check` will not yet see their keys. They verify with `pnpm test src/lib/i18n` plus
their own components' test files, and the orchestrator runs the full gate after wiring.

## Forbidden for all subagents

| Forbidden | Why |
| --- | --- |
| `git push`, `gh pr create`, any remote write | Only the orchestrator promotes. |
| Editing `src/lib/i18n/namespaces/index.ts` or `scripts/i18n-shots/index.ts` | Orchestrator wires these; see deviation above. |
| Editing `src/lib/i18n/locales.ts` | `th my mfa ar` are already registered. |
| Editing `src/lib/i18n/messages/<locale>.ts` (`th`/`my`/`mfa`/`ar`) | Generated by `pnpm i18n:import`. |
| `pnpm test:e2e*`, `pnpm dev`, `scripts/e2e-up.ts`, `pnpm i18n:shots` | **One e2e stack per machine.** Concurrent runs reset each other's database and there are ~20 live worktrees on this box. Orchestrator runs these serially. |
| Touching `src/pages/Homepage/`, `src/pages/CaseStudy/`, `src/pages/Beta/`, `src/pages/PrivacyPolicy.tsx` | English-only prerendered marketing; `t()` there breaks prerendering. |
| Calling `t()` from `src/lib/**` | `t()` is a hook. Out of scope (AQU-510). |
| Another agent's owned files | Partition is disjoint by construction. |
