Sample files the tutorial videos use.

- `psalm-23.usfm`: Psalm 23 in the King James Version (public domain), for
  the "Import a file" video. Not John, so it does not collide with the demo
  project's John 1.
- `recordings/JHN_001_00N.mp3`: six short speech clips, named by verse so the
  recordings upload places each on John 1:N of the demo project. They are
  generated narration, not readings of those verses: the videos never play
  them, they only show the takes and edit them.
