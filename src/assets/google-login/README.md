# Self-hosted Google sign-in branding

These assets are served by Aquilla. Do not replace them with Google-hosted URLs,
a Google Fonts stylesheet, an SDK, preconnect, or preload to a Google domain.

- `g-logo.png`: unmodified official gradient G from
  https://developers.google.com/static/identity/images/g-logo.png
- `google-sans-medium.woff2`: Google Sans Medium from the official Google Fonts
  CSS endpoint (`family=Google+Sans:wght@500`), losslessly repackaged from TTF
  using fontTools/Brotli. Licensed under the accompanying `OFL.txt`; see also
  `TRADEMARKS.md`. No glyph subsetting or design changes.
- Font license and trademark notice: https://github.com/google/fonts/tree/main/ofl/googlesans

https://developers.google.com/identity/branding-guidelines
